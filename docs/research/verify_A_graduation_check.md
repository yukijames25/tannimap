# 検証A：卒業要件・GPA・JASSO適格認定チェッカー（作る前の反証調査）

調査日：2026-11-19
目的：「学生が自分の成績を、自分の大学の規則（区分別の卒業・進級要件、その大学のGPA規則、JASSO給付奨学金の単位基準）に照らして確かめるツール」が、本当に困っていて、まだ誰も解決していない問題かどうかを確かめる。案を潰す証拠も、支える証拠と同じ重さで探した。

表記：**【事実】**＝出典で確認した内容。**【推測】**＝私の解釈・見積もり。知恵袋の投稿は言い換えのみで、個人を特定できる情報は書かない。

---

## 結論（先に）

**判定：作る（ただし大きく変える）**。元の案（便覧→YAML＋成績を貼ってチェック）のまま、どの大学の学生にも配る形はおすすめしない。

- 案を弱める最大の事実：**多くの大学（特に私大）は、ポータルで区分ごとに「必要・修得・不足」をすでに表示している**。履修中の科目を含めた見込みシミュレーションまである大学もある（東京外大、文教大、南山大など）。不足数を計算するだけなら、それらの大学では今ある機能と重なる。
- 先行調査が根拠にした東京外大の「起こりうる単位修得ミス」も、実は同大学のポータル「卒業要件確認表」（不足欄が赤くなる）とセットで出ている資料。**「不足が見えない」ことの証拠ではなく、「見えていても規則の読み違いで落ちる」ことの証拠**として読むべき。
- 一方で、穴は確かにある：
  - (a) ポータルが区分ごとの修得数しか出さず、充足の判定はしない大学がある。新潟大は学部が配る Excel チェックシートに頼り、法学部は2022年に学務係による確認をやめた。名古屋大工学部は自分で照合するよう案内している。
  - (b) 判定があっても、必修の個別科目、認定待ちの単位、他区分への流用（余った単位を別区分に回すこと）がポータルに出ないケースがある。
  - (c) 知恵袋の質問で多いのは「計算」より「表示や規則の意味が分からない」「この計画で間に合うか」のほう。
- 知恵袋の2023〜2026年の質問13件のうち、この道具が**はっきり答えられた**のは3件（約23%）。部分的に役立つのは5件、役立たないのは5件。
- 既存アプリ（Penmark、すごい時間割）は区分別の卒業要件チェックをしていない。ただし競合は「アプリ」ではない。**大学自身が作り始めている**。筑波大芸術専門学群は、Twins の成績 Excel をブラウザ内だけで判定する Web ツールを公開している（元の案とほぼ同じ形）。新潟大・法政大・香川大はチェックシートを出している。早稲田は RAG チャットボットを入れ、京都産業大は履修計画の生成AIを2027年に試験導入する予定。
- JASSO：本人が判定できるのは**単位数の基準（標準単位数の6割・7割）だけ**。GPA下位4分の1（学部・学科内の順位）と出席率は、大学しか持たない情報で決まる。

変更の提案は最後の節にまとめた。要点は3つ：
- 狙う場面を「履修登録前の計画チェック」と「ポータル表示や規則の意味の説明（便覧ページ付き）」に絞る。
- 狙う大学を「ポータルが判定しない大学・学部」に絞る。
- 作る前に、その条件に当てはまる学生3人に実際に使ってもらう。

### 1-3. 判定があっても抜ける部分【事実】

- 東京外大：留学単位認定、編入の自動認定、既修得単位認定は、次に成績が公開されるまで反映されない。「対象の科目の単位数をご自身で加えてご確認ください」（上記マニュアル）。
- 文教大学（越谷）：余った単位を他領域に流用するとき、成績照会では科目の開設領域で集計され、「流用可能な領域に含んで表示されません」。大学側の卒業要件チェックは自動で流用して計算する。**画面の不足表示と実際の判定が食い違う**作りになっている。https://www.koshigaya.bunkyo.ac.jp/kyomu/wp-content/uploads/sites/10/2022/04/d3af7b865cfa9193e2df91d431aca1f8.pdf
- 國學院：判定は4年生だけ。
- 法政：判定は学期末時点。登録予定の単位を足すには学部のチェックシートが必要。法政大学人間環境学部のチェックシートには「毎年、単位の計算ミスの為に留級・卒業保留となる学生がいます」とある。https://gakububbs.hosei.ac.jp/wp-content/uploads/jinkan2022-2025.pdf
- 新潟大：必修の個別科目と重複修得はシートでも判定できない。

### 1-4. どれくらい普及しているか

- 【事実】製品別のシェアや導入校数は公的には集計されていない（解説記事 https://www.issoh.co.jp/column/details/16859/ ）。JAST（GAKUEN／UNIVERSAL PASSPORT）は導入実績を「481校」と表示している（短大・専門学校・高専を含む）。製品トップページに卒業要件判定の記載はない。https://www.jast-gakuen.com/
- 【推測】今回、学生向けマニュアルを公開している大学では、区分別の「必要・修得・不足」表示や見込み判定を持つところが多かった（私大中心に9校前後）。判定しないのは国立大学の一部学部（新潟、名古屋工、筑波など）。ただしこの数え方には偏りがある。機能がある大学ほどマニュアルを公開するので、検索で見つかりやすい。全国の割合は推定できない。
- 【推測】それでも、「大学の学生のほとんどは、ポータルで区分別の不足を見られない」という前提は**成り立たない**。中〜大規模の私大の学生にとって、区分別の不足数を計算するだけの道具は重複になる。価値が残るのは、判定しない大学、ポータルに出ないもの（認定待ち・流用・必修の個別科目・予定科目）、そして表示の意味の説明。

## 5. JASSO 給付奨学金の適格認定（学業）

### 5-1. JASSO 原文の基準【事実】

出典：
- https://www.jasso.go.jp/shogakukin/saiyochu/kyufu/tekikaku_gakuryoku.html
- https://www.jasso.go.jp/news/__icsFiles/afieldfile/2025/11/11/kyuhu.pdf
- 2026年度 給付奨学生のしおり https://www.jasso.go.jp/shogakukin/saiyochu/siori/__icsFiles/afieldfile/2026/04/01/2026_kyuhushiori.pdf

**廃止**（次の1〜4のどれか）
1. 修業年限で卒業できないことが確定した（2026しおり：学校が学修の充実のために延長を適当と認めた場合を除く）
2. 修得単位数の合計が標準単位数の**6割以下**
3. 履修科目の授業への**出席率6割以下**、その他の学修意欲が著しく低い状況
4. 警告に連続して該当（停止に当たる場合を除く）

**廃止（返還）**：やむを得ない事由がなく、「学修の実態が認められない」場合。具体的には累積の修得単位が標準単位数の**1割以下**、または出席率が**1割以下**。この場合は学年の始めにさかのぼって返還を求める。

**停止**：2回連続で警告になり、2回目の理由が「GPA等が**学部等における**下位4分の1」だけの場合（3回連続の警告は除く）。

**警告**（次の1〜3のどれか）
1. 修得単位数の合計が標準単位数の**7割以下**
2. GPA等が学部等における**下位4分の1**
3. 出席率**8割以下**、その他の学修意欲が低い状況

**共通**：災害、傷病その他やむを得ない事由があれば、廃止・警告にならない場合がある。判定は学年末（2年以下の課程・高専は半期ごと）に、学校の報告にもとづいて行う。

**標準単位数**：JASSOのページには定義が書かれていない。大学資料では「（卒業必要単位数÷修業年限）×在学年数」。
- 名古屋市立大学：https://www.nagoya-cu.ac.jp/media/kyuufu_gakugyoukijunn.pdf
- 明治学院大学：https://www.meijigakuin.ac.jp/gakusei/scholarship_guide/2024GUIDE_05.pdf

**大学ごとの運用差**（名古屋市立大学の例）
- GPA下位4分の1は「学科単位で該当年度の『年度毎GPA』」で判定。
- 「出席率」は「失格等科目数が年間履修科目数の4分の1以上（廃止）／5分の1以上（警告）」に置き換えている。
- 医・薬・看護は国家試験合格率で読み替える特例がある。
- 社会的養護の特例がある。

### 5-2. 学生が自分で判定できるか

| 基準 | 自分で判定 | 理由 |
|---|---|---|
| 修得単位 ≦ 標準単位数×0.6／0.7／0.1 | **できる**【推測】 | 卒業必要単位数・修業年限・在学年数・修得単位はどれも本人が分かる。ただし「修得単位」に卒業要件外の単位（教職など）を含めるかは大学による【推測：要確認】 |
| 修業年限で卒業できないことが確定 | **ほぼできる** | 区分別の卒業要件チェックそのもの。ここは本体の機能とつながる |
| GPA下位4分の1 | **できない** | 学部・学科内の順位は大学だけが持つ。比べる母集団（学部か学科か、年度か累積か）も大学ごとに違う（上の名古屋市大の例） |
| 出席率 | **ほぼできない** | 出席の記録を持つのは大学で、定義も大学ごとに違う |

## 6. 判定と変更案

### 判定：**作る（変更あり）**。元の形のまま、汎用の不足計算ツールとしては作らない。

**作らない理由になりうる証拠（重い順）**
1. 多くの大学（特に私大）では、ポータルが区分別の不足や見込み判定をすでに出している（1-1）。
2. 知恵袋で明らかに効くのは約4分の1。4年の冬の不安には、大学の判定や卒業見込証明書のほうが強い（2章）。
3. 大学自身がチェックシート、ブラウザ内の判定ツール、生成AIチャットボットで穴を埋め始めている（1-2、3章）。
4. 規則の表現が複雑で（4章）、汎用 YAML ＋ AI 抽出の誤りが「卒業できる」という誤った安心につながるリスクがある。

**それでも作る価値が残る理由**
1. 判定をしない大学・学部が確かにあり、学務係が確認をやめた例まである（新潟大法学部）。そこの学生は Excel や紙で自分で照合しており、その作業は手間がかかって間違えやすい。
2. ポータルがあっても抜ける部分（予定科目、認定待ち、流用、必修の個別科目、なぜその数字になるのかの説明）は残る。
3. 正しさを確かめる正解データ（公式チェックシート、東京外大のミス一覧）が公開されているので、検証できる作り方が可能。

### 変更案

1. **狙う大学を「ポータルが判定しない大学・学部」に限る。** まずは1校1学部で始める。候補は、新潟大学（法・経済科学：公式 Excel が正解データになる）か、名古屋大学工学部（要件が2つの資料に分かれる）。私大で判定がある大学は対象外と明記する。
2. **狙う場面を2つに絞る。**
   - (a) **履修登録前の計画チェック**：修得済み＋登録予定で、区分別の過不足、上限超過、進級要件を見る。読み違いが致命的になる前に効く場面（#8, #4）。
   - (b) **「なぜこの数字なのか」の説明**：ポータルや公式シートの不足表示を、便覧の該当ページと規則で説明する（#13、文教大越谷の流用表示、東京外大のQ2「6単位取ったのに4単位表示」）。
   - 4年の冬に「卒業できますか」と聞く人は主な対象にしない。大学の判定と卒業見込証明書が答えになるため。
3. **出力は「判定」ではなく「照合表＋根拠ページ＋大学に確認すべき点の一覧」にする。** #3の回答者が勧めた「区分ごとの過不足表と、解釈が不明な点だけの質問」を自動で作る。これなら、新潟大法学部のように「学生が自分で確認する」方針の大学とも矛盾しない。
4. **YAML の部品を最初から用意する。** 算入上限、「ちょうど」型、階層の積み上げ、合算条件、同じ言語・同じ群の条件、上限付きの振替、入学年度と学生属性の分岐、進級要件（登録単位を分母にするものを含む）、特定科目の必須。表現しきれない規則は「未対応：便覧p.○を自分で確認」として明示する。
5. **入力は「ポータルの帳票を読む」側に寄せる。** 成績の貼り付け形式は大学ごとに違う（新潟＝成績確認表PDF、筑波＝Twins Excel、法政＝成績通知書PDF）ので、ここが本当の手間になる。エージェントが帳票PDFやExcelも読み、科目を区分に割り当てる案を出し、学生が確認する流れにする。
6. **JASSO は付録扱い。** 単位の6割・7割・1割のラインだけを計算し、GPAと出席は「大学が判定」と明示する。GPAはその大学の式（不可を分母に入れるか、再履修の扱い）での計算までにとどめる。
7. **作る前に確かめること（顧客を最初に考える方針）。** 判定のない大学の学生3人に、公式チェックシートを手で埋める作業を見せてもらう。かかる時間と間違いを測り、「便覧PDF→YAML→照合表」がそれより速く正確かを、公式シートとの一致率で確かめる。一致率と所要時間が公式シートの手作業に勝てなければ作らない。

### 残った不確かさ

- 全国でポータル判定がある大学の割合は推定できなかった。偏りのない抽出（例：国立大学をランダムに10校選んで学生向けマニュアルを確認）が次の一手。
- 早稲田（403）、専修（伝聞）の一次資料は未確認。
- JASSO の「修得単位数」に卒業要件外の単位を含めるかは、JASSO原文に定義がなく未確認。
