# 効果測定（代役の利用者テスト）

masume・kanjiframe と同じく、利用者役のエージェントに実際の相談文だけを渡して使わせ、詰まった所を直して測り直す。
tannimap の要は「AI が初めて見る便覧から、正しい規則ファイルを作れるか」なので、次の2つを測る。

1. **利用者への答えが正しいか**：仕込んだ落とし穴を見つけたか
2. **AI が作った規則ファイルの正しさ**：人（私）が便覧から作った正解の規則と、ランダムな成績で判定を比べる（`tools/compare_rules.py`）。
   比べるのは区分の名前に依存しない結果：卒業単位に数えた単位（修得済／予定込み）、不足、数に入らない単位、規則にない区分、すべて満たすか、進級要件の可否。
   ランダムな成績には、利用者の成績表に出てくる区分名だけを使う（AI が知りようのない区分名で減点しないため）。

## 1回目（2026-11-20、コミット 6cc74ed）

- 資料：法政大学 人間環境学部「進級・卒業単位チェックシート（2022〜2025年度入学者用）」（1ページ、公開PDF）
- 利用者役：2024年度入学の3年生。「来週から履修登録。取る予定の科目で4年に進級できるのか、卒業までに何が足りないのか不安」
- 成績（架空、私が作成）に仕込んだ落とし穴：200番台の諸外国語（3年→4年の進級要件）が無い、5群選択・キャリアチャレンジ・自由科目が修得上限を超えている、コースコアが足りない、LA3群を落としている（F）

| 指標 | 結果 |
|---|---|
| 進級できない原因（200番台の諸外国語）を見つけたか | **見つけた**（回答の最初に書いた） |
| 数に入らない単位（計7単位）を正しく説明したか | **正しい**（3つとも理由つき） |
| 予定込みでも残る不足（ILAC 6・コースコア 6・展開 16） | **正しい** |
| AI の規則 vs 正解の規則（ランダムな成績500通り） | 卒業の判定は**すべての項目で100%一致**。進級要件は85.8%一致 |
| tannimap の実行 | 10回（`--help` 5回を含む）、つまずき2回 |

進級要件の不一致は、2年→3年の要件を、AI は「人間環境学への招待 2単位・基礎演習 2単位を別々に」、正解の規則は「フレッシュマン科目 4単位」と書いたため。
チェックシートには2行それぞれに「2単位□」があるので、**AI の読み方のほうが字面に忠実**だった。不一致が出たのは、ランダムな成績がこの2科目に2単位以外の単位数を付けたときだけ。

代役が挙げた問題と直したこと：

| 指摘 | 直したこと |
|---|---|
| 評語ごとの点数を書かなかったのに、どこかの既定の点数で GPA が出た（「あてにしないで」と利用者に書く羽目になった） | 規則に `grading.gpa` が無ければ GPA は計算しない |
| 「1年次に8単位以上」のような年次ごとの要件が書けない | `progression` に `in_year` を追加し、`check --entry-year` で判定 |
| 進級要件が修得済みだけで判定され、予定込みで足りるかが分からない | 修得済みと予定込みの両方を表示 |
| 推測で書いた区分名（成績表に1件も無い）が、警告なしで0単位になる | 「成績表に一度も出てこない区分名」を警告 |
| `explain` が学務に聞くことと注意書きを出さない | 出すようにした |
| ページ番号の無いチェックシートで「p.チェックシート…」と表示される | 数字で始まらない page はそのまま表示 |
| `match` の中の条件が「かつ」か「または」か、`progression` に書けるキー、終了コードの意味が分からない | SKILL.md と `--help` に書いた |

## 2回目（2026-11-20、コミット 88cae3a、別の大学）

- 資料：香川大学「全学共通科目に関する卒業要件（2025年度入学者）」（17ページ、公開PDF）。学部ごとのページから自分の学部を探し、凡例のページ（「（ ）付きは上限」「○単位は超えても認めない」）も読む必要がある
- 利用者役：教育学部 小学校教育コース 2025年度入学の2年生。「同じ授業を2回取っちゃったのとか、数に入るのか分からない。全学共通科目で何が足りないか、ムダになっている単位があるか」
- 成績（架空、私が作成）に仕込んだ落とし穴：ライフデザイン・健康スポーツ・学問への扉・広範＋高度教養が上限超え、同じ授業科目（心理学）を2回、履修できない「教育学」、英語4＋ドイツ語4（1種類6単位に届かない）、理系科目を不可、必修の法学Aが予定のみ

| 指標 | 1回目 | 2回目（別の大学） |
|---|---|---|
| 仕込んだ落とし穴を見つけた数 | 6 / 6 | **9 / 9** |
| 数に入らない単位の説明（理由とページ） | 正しい（3件・7単位） | **正しい（6件・10単位）** |
| AI の規則 vs 正解の規則（500通り） | 卒業の判定 100%、進級 85.8% | **全項目 100%** |
| tannimap の実行 | 10回、つまずき2回 | 8回、つまずき2回（うち1回は PDF が Read で開けない環境の問題） |

- 2回目は、利用者が「全学共通科目だけ」を見たいという相談だったので、代役は合計を32単位（全学共通科目の小計）にし、専門科目を外した。正解の規則も同じ範囲にそろえて比べた。
- 代役は凡例（p.13）を読んで「○単位」を「ちょうど○単位・超えても認めない」と正しく解釈し、`min` と `max` を同じ値にした。

代役が挙げた問題と直したこと：

| 指摘 | 直したこと |
|---|---|
| 照合しない区分（専門科目）を `counts:false` にすると「卒業単位に含まれない」と出て、ムダな単位だと誤解される | `"out_of_scope": true` を追加。「今回は照合していない区分（数に入らないという意味ではない）」と別に表示 |
| 同じ授業科目の判定が完全一致だけ（「心理学A」「心理学B」） | `per_name_key`（正規表現）で「同じ授業科目」の決め方を指定できるように |
| 上限で外した授業がどれか分からない（心理学2回のうちどちらか） | 数に入らない単位に年度を表示 |
| 不可の科目が報告のどこにも出ず、理系0単位の理由が分からない | 「不合格の科目」を一覧に |
| 問題のある区分が表で目立たない（外国語の行が 8 で、満たしているように見える） | 問題のある区分に「!」 |
| `per_name_exclude` の書き方、「○単位」の扱い、page の付け方、科目数の条件、学生に確かめられない場面 | SKILL.md に書いた |
